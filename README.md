# JavaPortScanner



A simple TCP port scanner made with Java for learning purposes.



Um simples scanner de portas TCP desenvolvido em Java para fins de aprendizado.



## 🇺🇸 English



### About



JavaPortScanner scans a range of TCP ports on a given IP address or hostname and identifies which ports are open.



The project uses multithreading to scan multiple ports concurrently.



### Features



\* IP/hostname validation

\* TCP port scanning

\* Port range validation (`1-65535`)

\* Open, closed, filtered, and error status handling

\* Common service identification (HTTP, HTTPS, SSH, SMB, etc.)

\* Multithreaded scanning using `ExecutorService`



\### Technologies



* Java

* Java Sockets

* TCP

* Multithreading

* ExecutorService

* NetBeans


### Example



Enter IP address:

127.0.0.1



Enter starting port:

1



Enter ending port:

500



Scanning 127.0.0.1 from port 1 to 500.



135 is Open - MS RPC

445 is Open - SMB



Total open ports: 2
